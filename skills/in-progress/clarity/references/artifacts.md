# Artifacts

Use when the input is a messy note, thread, spec fragment, or half-formed concept whose core point and boundaries are blurred.

## Moves

- **Extract the real thesis.** State in one plain sentence what the artifact is actually trying to assert, ask for, or decide — ignoring preamble and hedging.
- **Split conflated concepts.** Spot nouns or verbs carrying multiple jobs (e.g., *"account"* meaning both billing entity and login user; *"launch"* meaning both code deploy and public announcement) and name each concept distinctly.
- **Test boundaries with concrete cases.** Check the core claim against one obvious case and one edge case; wherever the claim breaks or turns vague, surface that seam in **The crux**.
- **Cut tangential threads.** Separate material that supports the thesis (**signal**) from background lore, tangents, or premature details (**noise**) to remove or defer.
