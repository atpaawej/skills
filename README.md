# Skills

Personal collection of agent skills for engineering and productivity workflows.

## Installation

Link active skills (`engineering/`, `productivity/`, `in-progress/`) into your local agent directories (`~/.agents/skills` and `~/.claude/skills`):

```bash
./scripts/link-skills.sh
```

Re-run `./scripts/link-skills.sh` after adding, renaming, moving, or removing skills.
