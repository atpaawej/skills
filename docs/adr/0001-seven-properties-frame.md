# The seven properties are the test-quality frame

Test quality has two canonical rubrics — Kent Beck's twelve desiderata and Vladimir Khorikov's four pillars — and neither is applied by an agent reading them. We compressed both into seven plain-language questions, each answerable yes or no about a concrete test, and made the twelve named defects evidence of a failed property rather than a vocabulary to memorise. Considered and rejected: a defect-first catalogue (gives names without a target to aim at), and a mode-first split into write/review/diagnose sections (repeats the same doctrine three times). Speed and coverage are deliberately outside the frame: speed is a cost, and a coverage delta has never shown that an assertion holds, so scoring either invites optimising the metric instead of the proof.
